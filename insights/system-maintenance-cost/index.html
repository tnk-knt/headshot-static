01 — COST

システム保守費用は「対応範囲」と「必要な体制」で変わる

保守費用を比較するときに最初に確認したいのは、月額そのものではなく、その金額で何を依頼できるかです。 たとえば、異常を検知して連絡するだけの監視と、障害原因の調査から復旧まで行う保守では、必要な体制も工数も異なります。

また、平日日中だけの対応か、夜間や休日も含むのか、軽微な改修を月額内で扱うのか、別途見積にするのかでも料金は変わります。 そのため、「月額いくら」ではなく「その月額に何が含まれ、どこから別料金になるか」を揃えて比較することが重要です。

02 — SCOPE

システム保守費用に含まれる主な作業

障害・問い合わせ対応

エラーや不具合の事象確認、ログ調査、原因切り分け、復旧対応など。どこまでが月額内かを確認します。

監視・ログ確認

サーバーやアプリケーションの稼働状況を確認します。検知と通知だけか、一次対応まで含むかで内容が変わります。

バックアップ

バックアップの取得だけでなく、保存期間、復元手順、定期的な確認まで含むかを見ます。

更新・セキュリティ対応

OS、ミドルウェア、フレームワーク、ライブラリなどの更新調査や適用をどこまで行うか確認します。

仕様変更・小規模改修

画面項目の変更や小さな業務改善を月額内で行うのか、都度見積にするのかを明確にします。

運用資料・報告

作業履歴、構成情報、運用手順、問い合わせ記録などを更新し、属人化を減らすための管理も保守の一部です。

04 — FACTORS

保守料金が変わる6つのポイント

1. システムの規模と複雑さ

画面数や利用者数だけでなく、外部サービス連携、バッチ処理、データ量、サーバー構成などが増えるほど確認対象が広がります。

2. 対応時間帯とサービスレベル

平日日中のみか、夜間・休日も対象か、障害発生時にどの程度の初動時間を求めるかで必要な体制が変わります。

3. 監視・バックアップの範囲

死活監視だけか、性能やログまで見るか、バックアップの復元確認まで行うかによって作業量は異なります。

4. 障害対応の範囲

原因調査までか、アプリケーション修正やインフラ対応、外部ベンダーとの調整まで含むかを確認します。

5. 軽微な改修を含むか

毎月一定時間の改善作業を含む契約と、障害対応だけを固定費にして改修は別途見積とする契約では、月額の考え方が変わります。

6. ドキュメントと属人化の状態

設計書や運用手順が不足し、特定担当者しか分からない状態では、保守開始前の調査や情報整理に時間が必要になることがあります。

05 — CHECK

保守契約を見直すときのチェック項目

  • 現在の月額に含まれる作業を具体的に説明できるか
  • 実際に利用していない対応や体制へ費用を払っていないか
  • 障害時の一次切り分け、原因調査、復旧の責任範囲が明確か
  • 監視、バックアップ、更新作業の頻度と担当が決まっているか
  • 軽微な改修と追加見積の境界が明確か
  • 契約期間、更新、解約条件を確認できているか
  • ソースコード、サーバー、クラウド、ドメインなどの管理主体が把握できているか

「毎月費用を払っているが何をしているのか分からない」「小さな修正でも毎回別料金になる」と感じる場合は、まず契約書と過去の対応履歴を並べ、契約内容と実際の利用状況が合っているかを確認すると整理しやすくなります。

契約やベンダー提案そのものの妥当性を第三者の立場で確認したい場合は、IT顧問での見積・契約内容の整理も選択肢です。

06 — SWITCH

保守会社を変更するときに先に確認したいこと

保守会社を変える場合は、料金比較より先に「新しい会社が保守を開始できる状態か」を確認する必要があります。 公開されている引き継ぎガイドでも、ソースコードの権利や入手可否、アクセス権限、現行業者から受け取る情報、移行期間などが重要な確認項目として挙げられています。

保守会社変更時の参考情報を確認する →

  • ソースコードとバージョン管理リポジトリ
  • 設計書、構成図、運用手順、問い合わせ履歴
  • サーバー、クラウド、ドメイン、DNSなどの管理権限
  • データベース、バックアップ、ログの場所とアクセス方法
  • 外部サービス、ライセンス、API等の契約主体
  • 現行保守会社との契約終了日と引き継ぎ可能期間

資料が不足していても直ちに引き継げないとは限りません。ソースコード、設定、ログ、現担当者へのヒアリングなどから必要情報を整理し、調査から保守開始までを段階的に進める方法があります。

08 — START

「保守費が妥当かわからない」段階から相談できる

いきなり保守会社を変更する必要はありません。現在の契約、システム構成、月々の対応内容を確認し、費用と支援範囲が合っているかを整理するところから始められます。

保守契約だけでなく、システム全体のリスクや更改の必要性まで一度整理したい場合は、スポットIT診断も選択肢です。

FAQ

よくあるご質問

システム保守費用は月額だけで比較できますか？

月額だけでは比較しにくいため、監視、障害対応、バックアップ、更新、改修、対応時間帯、追加費用条件など、料金に含まれる範囲を揃えて確認することが重要です。

他社が開発したシステムでも保守会社を変更できますか？

技術構成、契約条件、ソースコードや環境へのアクセス可否を確認して判断します。引き継ぎ資料が不足している場合は、現状調査から始める方法もあります。

HeadShotの保守・改善は何を支援しますか？

公開している主な支援内容は、保守引き継ぎ、障害・問い合わせ対応、仕様変更・小規模改修、運用の見える化です。具体的な範囲は対象システムと課題を確認して整理します。
